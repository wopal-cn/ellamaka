能力本体包含 WopalSpace 使用的代理、技能、规则和工作流，是空间持续演化的能力来源。

## 推荐使用 Fork

- 能够同步上游能力更新
- 可以保存你自己的能力演化
- 便于跨设备恢复和协作

Fork 需要 GitHub 认证，用于创建你的本体副本、同步能力演化、参与生态贡献。可在 GitHub → Settings → Developer settings → Personal access tokens 生成（勾选 repo 权限），或已安装 gh CLI 时直接 `gh auth login`。

## 仅保存在本机

Clone 模式不需要 GitHub 认证，适合暂时不希望关联 GitHub 的本地环境；跳过认证即可使用，之后可升级为 Fork。

> 已存在的能力本体只会被复用，配置向导不会自动改变其同步模式。

**预计耗时：** 约 1–3 分钟
